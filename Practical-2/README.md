# StudentHub

## Practical 2 - Semantic HTML5 Website

### Description

StudentHub is a semantic HTML5 website developed as part of Web Development Practical-2.

### Features

- Home Page
- About Page
- Student Registration
- Student Login
- Dashboard
- Campus Events
- Student Profile
- Contact Page
- Admin Panel
- FAQ
- Feedback Form

### Technologies Used

- HTML5
- CSS3

### Accessibility Features

- Semantic HTML5
- Skip Navigation
- Breadcrumb Navigation
- Alt Text for Images
- Labels for Forms
