# StudentHub Portal

## Practical 1: Project Initiation and Requirement Analysis

### Project Description
StudentHub is a web-based portal designed to help students manage their academic activities in one place. It provides access to attendance, courses, assignments, timetable, notices, and student profiles.

---

## Objectives

- Analyze project requirements
- Identify user roles
- Design a sitemap
- Create low-fidelity wireframes
- Set up the project folder structure
- Prepare the project repository on GitHub

---

## User Roles

### Student
- Login
- View Profile
- Check Attendance
- View Courses
- View Timetable
- Submit Assignments
- View Notices

### Faculty
- Login
- Upload Assignments
- Upload Notices
- View Student Submissions

### Admin
- Manage Students
- Manage Faculty
- Manage Courses
- Manage Notices
